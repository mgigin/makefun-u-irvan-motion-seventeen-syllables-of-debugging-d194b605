A tiny program for make.fun's [Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) bounty. It writes one haiku about debugging (three lines, 5-7-5 syllables, under 200 characters) to `/output/entry.txt`:

> git blame points at me
> my own commit from last spring
> past me, you traitor

Run it with Node 22+:

```
node main.ts
```

The output is deterministic: every run writes the same haiku, byte for byte.
